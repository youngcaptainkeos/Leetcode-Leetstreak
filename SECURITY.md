## Reporting a Vulnerability

We take the security and integrity of LeetStreak and our users' data seriously. If you discover a security vulnerability, we appreciate your help in disclosing it to us responsibly.

### How to Report
Please **do not** open a public GitHub issue for security vulnerabilities. Instead:

1. Email us directly at: **[shashu2804@gmail.com](mailto:shashu2804@gmail.com)** or **[support@leetstreak.com](mailto:support@leetstreak.com)**
2. Provide a clear description of the vulnerability, including:
   - Steps to reproduce or proof-of-concept code.
   - The affected endpoint, component, or file.
   - Any potential impact on users or server infrastructure.

### What to Expect
* **Acknowledgment:** We will acknowledge receipt of your vulnerability report within 48 hours.
* **Resolution:** We will work promptly to investigate, verify, and implement a patch.
* **Responsible Disclosure:** We ask that you give us reasonable time to release a fix before publishing details publicly.

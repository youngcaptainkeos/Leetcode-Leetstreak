# LeetStreak 1.0.7

## Changes in this Release
- **Points Breakdown**: Displays "Base points (Unrated fallback)" for Codeforces solves where official contest ratings are pending.
- **Codeforces Scoring**: Codeforces problems with pending official contest ratings now receive a default fallback base of 15 points (equivalent to Medium).
- **Public Problem Lists**: Full support for importing public LeetCode problem playlists and lists directly into study plans.
- **Server Health**: Removed high-frequency background polling loop to eliminate database egress overhead.
- **Permissions**: No new Chrome permissions requested.

## Package & Upload
- **Version**: `1.0.7`
- **Upload File**: `leetstreak_dist.zip` (or `~/Downloads/leetstreak-1.0.7.zip`)
- Upload this zip directly to the Chrome Web Store Developer Dashboard under the existing LeetStreak extension listing.

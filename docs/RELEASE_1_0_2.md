# LeetStreak 1.0.2 — first recorded solves

- LeetCode accepts an unstored question as a first recorded solve under the
  owner-approved assumption; provider lifetime proof stays separately labeled.
- Repaired stored acceptance dates populate period counters without paying
  already-recorded questions again. Existing credited points are preserved.
- Future new questions receive base points once; repeats use the existing
  seven-day revision cooldown. Live daily eligibility follows the recorded-first
  rule, while imports and repairs remain excluded from new daily bonuses.
- Updated extension Help, solve details and website scoring copy. Existing
  permissions are unchanged. No reviewer credentials are packaged.
